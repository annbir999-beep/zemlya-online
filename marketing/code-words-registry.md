# Реестр кодовых слов (лид-магниты из роликов)

Кодовое слово = обещание в ролике («пиши СЛОВО в комменты — пришлю …»). На каждое
должен быть готовый актив и механизм выдачи, иначе лид сгорает. Статус выдачи ниже.

Легенда статуса: ✅ готово · 🟡 данные есть, механизма авто-выдачи нет · ⚠ актива нет.

| Слово | В каком ролике | Что обещаем | Чем выдавать | Статус |
|---|---|---|---|---|
| **ЗЕМЛЯ** | sell-transformation, sell-myth-bust, model-zemlya-v2-clean (3 ролика, одно слово!) | подборка лотов по региону подписчика | запрос к API: активные лоты по региону, топ по скорингу/дисконту | 🟡 данные есть, авто-выдачи нет |
| **ОЗЕРО** | sell-by-water (готов, в to-post/) | лоты у воды в его регионе | запрос по гео/«рекреация»/близость к воде | ⚠ фильтра «у воды» нет |
| **ПРОТОКОЛ** | one-bidder-aerial-v2 (готов, в to-post/) | 5 аукционов, прошедших с 1 заявкой | нужны данные о числе участников по лоту | ⚠ есть ли эти данные — проверить |
| **БАНКРОТ** | Банкротные торги (bankrupt) | 5 банкротных лотов с глубоким дисконтом | фильтр is_bankruptcy + сортировка по дисконту (в продукте ЕСТЬ) | 🟡 данные есть, авто-выдачи нет |
| **АРЕНДА** | sell-lease-to-buy (готов, в to-post/) | разбор схемы аренда→выкуп по шагам (ст. 39.3) | PDF/гайд-инструкция | ⚠ актив не готов |
| **ПРОВЕРКА** | sell-why-this-plot + ai-audit-aerial-v2 (2 ролика, ОДИН И ТОТ ЖЕ актив — чек-лист из 12 проверок) | чеклист проверок участка | PDF «12 проверок» (`backend/services/lead_magnet.py`) | ✅ готов |

⚠ **Грабля «одно слово — несколько роликов»**: ЗЕМЛЯ обещают 3 ролика, ПРОВЕРКА — 2. Бот
выдачи не должен зависеть от того, ИЗ КАКОГО ролика пришёл человек (это и не отследить в
комментариях) — просто отвечать на слово одинаково независимо от источника. Не плодить
разные ответы под один код.

Ссылочные CTA (не кодовые слова, self-serve на сайте, работают): AI-аудит,
регистрация, бесплатная школа/ссылка в шапке.

## Что нужно, чтобы обязательства выполнялись

1. **Активы**: собрать недостающие (АРЕНДА-гайд; шаблоны выдачи для ЗЕМЛЯ/БАНКРОТ/
   ПРОТОКОЛ — генерятся запросом к API по региону/фильтру).
2. **Авто-выдача**: комментарий/личка со словом → инбокс уже ловит (см. inbox-hub)
   → бот присылает материал в личку и логирует. Стыкуется с зоной агента-постинга
   и авто-отделом продаж — согласовать, чтобы не дублировать.
3. **Учёт**: таблица «кто написал слово / когда / выдано ли» — чтобы видеть
   выполнение и конверсию по каждому слову.

## Правило на будущее
Не обещать в ролике кодовое слово, под которое НЕТ готового актива в этом реестре
со статусом ✅. Сначала актив → потом ролик с обещанием.
