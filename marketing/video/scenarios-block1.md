# Блок 1 — «Возведение по таймеру» · раскадровка + промпты

Проект: **Торги Земли** (torgi-zemli.ru). Формат: вертикальные Shorts/Reels **9:16**, 30–55 сек.
Импортный файл для GoldWork: [`goldwork-import-block1.json`](goldwork-import-block1.json) — 8 пресетов, поля `scriptText / whiskPrompts / videoPrompts` строго 1:1 по сценам.

## Как залить в GoldWork
1. Вкладка **Сценарий** → блок «Пресеты сценария» → **«Загрузить из файла»** → выбрать `goldwork-import-block1.json`.
2. Появятся 8 пресетов «Блок1-01 … Блок1-08». Выбрать нужный → **«Загрузить»** — заполнятся озвучка, Whisk- и Veo-промпты.
3. Прогнать пайплайн. Озвучка — на русском (TTS/субтитры), визуальные промпты — на английском (так модели Whisk/Veo точнее держат сцену; на экране текста нет — в каждый промпт зашит запрет `no on-screen text, no letters, no signage, no flags`).

## Тех-памятка «без искажений» (единый каркас + персонажи)
- **Фиксированная камера** на весь ролик (один дрон-ракурс, low three-quarter). Меняется только стадия стройки.
- **Сначала генерим финальный кадр дома в Whisk**, затем его же силуэт/цвет фасада повторяем во всех ранних стадиях (в JSON описание дома намеренно одинаковое во всех строках сцены).
- Для Veo включать **image-to-video от Whisk-кадра** соответствующей стадии — так каркас и пропорции не «плывут».
- Фиксируем **золотой час** во всех сценах (свет не должен прыгать).
- Персонажи появляются только в финале: **славянская внешность, светлая кожа, без надписей/флагов на одежде**.
- Глобальные негативы (зашиты в каждый промпт): `no old wooden houses, no village, no flags, no on-screen text, no logos, no watermark`.

## Заметки по продакшену
- **Озвучка:** TTS (как в текущем пайплайне), тон — уверенный, тёплый, экспертный, без «инфоцыганства».
- **Субтитры:** крупные, по центру/снизу, POP-стиль; ключевые слова («полцены», «торги», «твой дом») — акцентным цветом.
- **CTA-плашка** в конце (графика поверх видео, не в кадре генерации): `torgi-zemli.ru` · `@torgi_zemli`.
- **Музыка:** брать lkw/royalty-free под указанный BPM; reveal-бит совмещать с появлением семьи/света — это эмоциональный пик.
- **Консистентность:** если каркас «плывёт» между сценами — перегенерить проблемную стадию в Whisk от финального кадра-референса, затем Veo image-to-video.
