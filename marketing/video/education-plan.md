# Обучающие видео «Как это работает» — план серии и сценарии

Формат: скринкаст интерфейса torgi-zemli.ru + озвучка (Edge TTS Dmitry) + субтитры.
Хронометраж 35–60 сек. Вертикаль 9:16 для соцсетей + горизонталь 16:9 для раздела на сайте.

Производство: записываю экран прода по сценарию (браузер + ffmpeg), озвучка и субтитры —
готовым конвейером из видео-фабрики. AI-генерация (GoldWork) — только для интро/обложек.

Раздел на сайте: /how-it-works «📚 Как это работает» — плитка видео + текстовые шаги под каждым.
