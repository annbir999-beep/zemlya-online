27.07.2026 по факту кода, а не по задумке. Держать в актуальном состоянии при
любой правке пейволла.

## 4. Грабли, из-за которых гейтинг ломался

**Голый `fetch()` вместо авторизованного (найдено 27.07.2026, поправлено).**
Каталог, карта и экспорт звались через `fetch()` без заголовка `Authorization`.
Бэкенд считал любого пользователя анонимом → резал премиум-поля и молча игнорировал
премиум-фильтры. Карточка лота при этом ходила через `api.get()` с токеном и всё
показывала — отсюда ощущение «то открыто, то нет». **Правило: любой запрос к
`/api/lots*` идёт через `api.get()` или `authFetch()` из `lib/api.ts`, никогда через
голый `fetch()`.**

**Тариф не отображался в кабинете.** В `PLAN_LABEL` не было ключа `enterprise` →
пустой бейдж. Плюс жили старые внутренние названия («Личный», «Эксперт», «Лендлорд»)
вместо публичных. **Правило: добавляешь тариф — правишь `PLAN_RANK` (бэк и фронт),
`PLAN_LABEL`, `PLAN_PRICES` и `/pricing` одним заходом.**

**TS-тип лота отставал от API.** `LotListItem` во фронте не знал про `deposit`,
`resale_type`, `deal_type`, `area_sqm_kn`, `last_price_drop_pct` — код читал их
вслепую. Синхронизировано. **Правило: меняешь pydantic-схему `LotListItem` —
правишь одноимённый TS-интерфейс.**

## 5. Контроль

Скрипт `scripts/check_gating.py` — прогоняет прод и проверяет, что анониму НЕ уходят
премиум-поля и что премиум-фильтры на нём не срабатывают. Запуск:

```bash
python scripts/check_gating.py
```

Что проверяется:
1. `GET /api/lots` без токена — в ответе нет `discount_to_market_pct`,
   `nearest_city_*`, `pct_price_to_cadastral`, `market_price_sqm`,
   `sublease_allowed`, `assignment_allowed`, `tor_zone`
2. Скор анониму приходит (это не баг, а решение — см. раздел 1)
3. Премиум-фильтр анониму игнорируется: `?score_min=90` даёт тот же `total`, что и без него
4. `GET /api/lots/export` без токена — 401/403, не 200

Прогонять после каждой правки пейволла и раз в неделю в составе утреннего чек-листа.
